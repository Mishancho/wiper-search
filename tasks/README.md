# Задачи: персональный рабочий поиск

Основание: [`docs/plans/2026-09-29-personal-search-workflow-design.md`](../docs/plans/2026-09-29-personal-search-workflow-design.md)

## Правила выполнения

- Задачи выполняются строго по порядку.
- Перед началом следующей задачи предыдущая должна пройти свои проверки.
- Каждая задача завершается отдельным локальным коммитом.
- Google Sheets остаётся единственным источником поисковой базы.
- История, избранное и ненайденные запросы не отправляются на сервер.
- Не добавлять функции из раздела «Не входит» утверждённого дизайна.

## Готовность всего функционала

- Все шесть задач завершены и отмечены в таблице.
- Автоматические тесты проходят.
- Основной пользовательский сценарий проверен в браузере на рабочем компьютере.
- Перезагрузка страницы сохраняет локальные данные.
- Ошибки сети, сервера и локального хранилища не ломают основной поиск.
- Обновлённый Service Worker не оставляет пользователю старые HTML, CSS или JavaScript.
