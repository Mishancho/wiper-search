# 04. Копирование артикулов

Статус: не начата  
Зависимости: 02

## Цель

Позволить переносить найденные номера в переписку или другую рабочую программу без ручного выделения текста.

## Объём

- Сделать каждый артикул результата доступным действием «копировать».
- Добавить группе результата действие «Копировать все».
- Копировать группу в простом читаемом текстовом формате: основной номер и полный набор артикулов без технических полей.
- После успеха показывать короткое ненавязчивое подтверждение.
- Использовать Clipboard API и браузерный резервный способ.
- При ошибке показывать понятное сообщение, не скрывая результаты.
- Не запускать новый поиск при копировании артикула.

## Предполагаемые файлы

- `static/js/app.js`
- `templates/index.html`
- `static/css/style.css`
- тестовые файлы браузерной логики

## Критерии приёмки

- Один клик копирует ровно выбранный артикул.
- «Копировать все» не дублирует номера и использует стабильный формат.
- Действия доступны мышью и клавиатурой.
- Подтверждение не требует закрытия и не перекрывает поиск.
- Отказ Clipboard API обрабатывается резервным способом.
- Полный отказ копирования не повреждает экран результата.

## Проверки

- Проверить содержимое буфера для одного артикула.
- Проверить содержимое для группы с несколькими аналогами.
- Проверить группу, где искомый номер является альтернативным.
- Проверить основной и резервный способы копирования.
- Проверить доступность с клавиатуры.

## Не входит

- экспорт в CSV или Excel;
- копирование сразу нескольких групп одной кнопкой;
- отправка в мессенджер.
