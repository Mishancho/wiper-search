# 03. Локальное хранилище, история и избранное

Статус: не начата  
Зависимости: 02

## Цель

Ускорить повторные поиски на рабочем компьютере без аккаунта, серверной базы и синхронизации.

## Объём

- Добавить защитный слой чтения и записи `localStorage` с отдельными версионированными ключами.
- При недоступном или повреждённом хранилище не блокировать основной поиск.
- Хранить последние 20 уникальных нормализованных запросов.
- Повторный запрос перемещать в начало истории без дубля.
- Добавлять в историю только завершённые поиски: найденные и корректно ненайденные.
- Запускать повторный поиск нажатием на элемент истории.
- Очищать историю только после подтверждения.
- Добавлять и удалять из избранного введённые и найденные артикулы.
- Запускать поиск нажатием на избранный артикул.
- Восстанавливать историю и избранное после перезагрузки страницы.

## Модель локальных данных

Каждая запись хранит нормализованный ключ и последнее отображаемое написание. История дополнительно хранит порядок последнего использования. Формат данных имеет явную версию.

## Предполагаемые файлы

- `static/js/app.js`
- `templates/index.html`
- `static/css/style.css`
- тестовые файлы или минимальная тестовая инфраструктура для браузерной логики

## Критерии приёмки

- История содержит не более 20 уникальных запросов.
- Разные варианты разделителей одного номера не создают дубли.
- Повторный запрос становится первым.
- Избранное можно переключить у введённого номера и у номера результата.
- Перезагрузка сохраняет оба списка.
- Некорректный JSON в одном ключе не удаляет другой список и не ломает поиск.
- При заблокированном `localStorage` поиск продолжает работать.

## Проверки

- Проверить лимит, дедупликацию и порядок истории.
- Проверить добавление и удаление избранного.
- Проверить восстановление после перезагрузки.
- Проверить повреждённые данные и исключения чтения/записи.
- Проверить повторный поиск из обоих блоков.

## Не входит

- синхронизация между браузерами;
- серверное хранение;
- экспорт истории;
- журнал ненайденного — он реализуется в задаче 05.
