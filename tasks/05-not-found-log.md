# 05. Журнал ненайденных артикулов

Статус: выполнена
Зависимости: 03

## Цель

Собирать на рабочем компьютере повторяющиеся пробелы поисковой базы, не смешивая их с техническими ошибками.

## Объём

- Добавить отдельный версионированный ключ `localStorage` для ненайденных запросов.
- Для каждого нормализованного артикула хранить последнее введённое написание, счётчик и время последней попытки.
- Увеличивать счётчик только после успешного ответа API с пустым `results`.
- Не учитывать пустой ввод, `400`, `503`, сетевые ошибки, невалидный JSON и другие ошибки сервера.
- Автоматически удалять позицию, если последующий поиск этого артикула дал результат.
- Показывать список в сворачиваемом блоке, сначала наиболее недавно искомые позиции.
- Запускать повторный поиск нажатием на позицию.
- Очищать весь список только после подтверждения.

## Предполагаемые файлы

- `static/js/app.js`
- `templates/index.html`
- `static/css/style.css`
- тестовые файлы браузерной логики

## Критерии приёмки

- Первый пустой результат создаёт позицию со счётчиком 1.
- Повторный эквивалентный запрос увеличивает тот же счётчик.
- Технические ошибки не создают и не изменяют позиции.
- Успешный найденный результат удаляет прежнюю запись этого артикула.
- Перезагрузка сохраняет список.
- Повреждённые данные журнала не ломают историю, избранное и поиск.
- Пустой журнал не занимает место на экране.

## Проверки

- Проверить создание, увеличение счётчика и порядок.
- Проверить все исключённые классы ошибок.
- Проверить автоматическое удаление после появления артикула в базе.
- Проверить повторный поиск из журнала.
- Проверить очистку с подтверждением и отменой.

Проверено: создание, повторный эквивалентный запрос, порядок и время, перезагрузка, replay, найденный результат основного и запасного поиска, исключение ошибок `400`/`503`/`500`, сети, JSON и структуры ответа, ошибка запасного поиска, очистка с подтверждением и отменой, изоляция категорий, повреждённое и недоступное `localStorage`.

- `python3 -m unittest discover -s tests -v`: 18 тестов прошли.
- `node tests/test_ui.cjs` с Playwright из workspace runtime: проверки обеих категорий, адаптивности, истории, избранного, копирования и журнала прошли на локальном fixture-сервере.
- `node --check static/js/app.js`, `node --check tests/test_ui.cjs`, `git diff --check`: прошли.

- автоматическое создание позиции в поисковой базе.
