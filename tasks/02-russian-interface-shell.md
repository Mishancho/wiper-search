# 02. Русский интерфейс и UI-каркас

Статус: не начата  
Зависимости: 01

## Цель

Привести экран к реальному назначению приложения и подготовить компактные места для персональных функций, не реализуя их поведение раньше следующих задач.

## Объём

- Перевести заголовок, описание, подсказки, загрузку, пустой результат, ошибки и подпись внизу на русский язык.
- Указать, что приложение ищет аналоги дворников и тормозных колодок.
- Перевести известные секции результатов: передние дворники, задние дворники, дворники, тормозные колодки.
- Для неизвестной секции использовать нейтральное название без ошибки.
- Подготовить скрываемые контейнеры «Избранное», «Недавние» и «Не найдено в базе».
- Подготовить доступную область для коротких уведомлений о копировании и локальном хранилище.
- Сохранить одноэкранную компоновку и мобильную адаптивность.

## Предполагаемые файлы

- `templates/index.html`
- `static/css/style.css`
- `static/js/app.js`
- `static/manifest.json`

## Критерии приёмки

- На экране не остаётся текста, утверждающего, что поиск работает только с дворниками.
- Все пользовательские сообщения согласованы на русском языке.
- Пустые персональные блоки не занимают место.
- Основное поле и кнопка поиска остаются главным визуальным действием.
- Интерфейс пригоден для клавиатуры и не зависит от hover-состояний.
- На узком экране элементы не выходят за границы.

## Проверки

- Проверить успешный результат, пустой результат, `400`, `503` и сетевую ошибку.
- Проверить desktop и узкую мобильную ширину.
- Проверить поиск по Enter и кнопке.
- Запустить Python-тесты, чтобы убедиться в отсутствии регрессии API.

## Не входит

- полноценная история;
- избранное;
- копирование;
- учёт ненайденных позиций.
