# Постоянно видимые соответствия для тормозных колодок

## Цель

При поиске тормозных колодок пользователь должен сразу видеть исходные варианты из таблицы: оригинальный и неоригинальные аналоги. Для щёток стеклоочистителя длинный список каталожных соответствий остаётся сворачиваемым.

## Интерфейс

- Вверху результата остаётся главный складской артикул с меткой «В заказ-наряд» и кнопкой копирования.
- На странице колодок сразу под ним постоянно выводятся строки «Оригинальный аналог» и «Неоригинальные аналоги».
- У каждого отображаемого значения остаётся отдельная кнопка копирования.
- Пустые значения, дубликаты между собой и значение, совпадающее со складским артикулом, не выводятся.
- На странице дворников используется существующий сворачиваемый блок «Показать каталожные соответствия».

## Проверки

- Оба поля колодок видны без раскрытия блока на desktop и мобильном экране.
- Значения можно копировать мышью и клавиатурой.
- У колодок нет блока раскрытия каталожных соответствий.
- Дубликаты и пустые поля не появляются.
- Выдача дворников, переходы между категориями, история и журнал ненайденных не регрессируют.
