# Складской артикул в выдаче и изоляция категорий

## Цель

Сделать приложение инструментом перевода каталожного номера в складской артикул для заказ-наряда. В большинстве случаев пользователь копирует номер из левого столбца Google Sheets, но должен видеть и проверять каталожные соответствия из правого столбца. Дворники и тормозные колодки не должны смешиваться.

## Выдача результата

Каждая найденная группа показывает:

1. Метку «В заказ-наряд».
2. Складской артикул из левого столбца как главное значение с отдельной кнопкой копирования.
3. Строку «Найдено по запросу: …».
4. Сворачиваемый блок «Показать каталожные соответствия (N)». В нём отображаются номера из правого столбца; они остаются выделяемым текстом и могут копироваться по одному для редких исключений.

Главный номер не повторяется среди каталожных соответствий. При нескольких складских группах выдача показывает предупреждение «Найдено несколько вариантов — требуется проверка». Интерфейс использует формулировку «Совпадение в таблице», а не утверждает гарантированную применимость.

## Изоляция категорий

Загрузка данных должна присваивать каждую таблицу или запись ровно одной категории. Определение опирается на структуру и заголовки таблицы, а не на совпадение самих артикулов. Нельзя строить оба индекса из одного источника по умолчанию.

- Дворники попадают только в индекс дворников.
- Тормозные колодки попадают только в индекс колодок.
- Если один и тот же номер существует в обеих категориях, активная страница показывает только свою группу.
- Если в активной категории ничего не найдено, а точное совпадение есть в другой, приложение показывает только нейтральную подсказку с действием перехода. Чужие результаты на странице не отображаются.

Для безопасного определения категории реализация должна использовать явный сигнатурный признак таблицы: заголовки колонок и число смысловых колонок. Неоднозначный источник не публикуется в оба индекса; он должен быть исключён из снимка с диагностикой, чтобы временная ошибка разметки не давала неверный артикул.

## Исключения

Текстовые пометки внутри ячеек наподобие `check mounting` не интерпретируются как номер детали автоматически. Существующие каталожные соответствия остаются доступны для ручной проверки. Отдельный необязательный столбец «Примечание» для исключений возможен позже, но не является частью этой поставки.

## Проверки

- По полному и сокращённому каталожному номеру находится соответствующий складской артикул.
- Главная кнопка копирует складской номер; каталожный номер можно скопировать только из раскрытого блока.
- Основной номер не дублируется среди соответствий.
- Несколько совпадений показывают предупреждение.
- Один идентичный номер в обеих категориях возвращает только результат активной категории.
- При отсутствии результата в активной категории подсказка о другой категории не смешивает выдачу и ведёт на правильную страницу.
- Копирование, история, журнал ненайденных, клавиатурная навигация и мобильная компоновка не регрессируют.
